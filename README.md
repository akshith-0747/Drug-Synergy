# 💊 Drug Synergy Prediction Using Machine Learning

**Drug Synergy Prediction** is a full-stack machine learning project developed to predict the synergistic effects of anticancer drug combinations across different cancer cell lines. The project combines drug information, drug-response data, cell-line information, and gene-expression data to build machine learning models capable of predicting multiple drug synergy scores.

The system predicts four commonly used synergy metrics: **ZIP (Zero Interaction Potency), Bliss, Loewe, and HSA (Highest Single Agent)**. These metrics provide different ways of measuring how the combined effect of two drugs compares with their individual effects.

The project uses multiple datasets containing drug combinations, chemical information, cell-line information, drug responses, and gene-expression profiles. The datasets are cleaned and matched based on drug names and cell-line names before being combined into a machine-learning-ready dataset. Since gene-expression datasets contain thousands of gene features, **Principal Component Analysis (PCA)** is used for dimensionality reduction. The final model uses **50 gene-expression principal components along with molecular-weight features for the two drugs**, resulting in **52 input features**.

Several machine learning algorithms are used for model development and comparison, including **LASSO, AdaBoost, Random Forest, XGBoost, and SynergyX**. XGBoost is used as the main prediction approach, while the other models are included for performance comparison. The models are evaluated using **R², Mean Absolute Error (MAE), Mean Squared Error (MSE), Root Mean Squared Error (RMSE), and accuracy within ±5 units**. Model-comparison tables and graphs are generated to analyze the performance of different algorithms across the ZIP, Bliss, Loewe, and HSA targets.

The machine learning pipeline is integrated with a **FastAPI backend** that loads the trained models and generates predictions based on the selected drugs and cancer cell line. A web-based frontend provides a simple interface where users can enter **Drug 1, Drug 2, and Cell Line**. The system then returns the predicted **ZIP, Bliss, Loewe, and HSA scores**, along with a **Combined Score and Synergy Label** for easier interpretation.

The project is implemented using **Python, Pandas, NumPy, Scikit-learn, XGBoost, Matplotlib, Joblib, FastAPI, Uvicorn, HTML, CSS, and JavaScript**. The project demonstrates an end-to-end machine learning workflow, including data preprocessing, feature engineering, dimensionality reduction, model training, model evaluation, model comparison, API development, and frontend integration.

### Main Workflow

**Raw Datasets → Data Cleaning → Drug/Cell-Line Matching → Gene Expression Processing → PCA → 52 Features → Model Training → Model Evaluation → Model Comparison → FastAPI Backend → Web Frontend**


### Technologies Used

**Python · Pandas · NumPy · Scikit-learn · XGBoost · Matplotlib · FastAPI · Uvicorn · HTML · CSS · JavaScript**


### Output

For a selected drug combination and cell line, the application produces **ZIP, Bliss, Loewe, HSA, Combined Score, and Synergy Label**. The project also generates evaluation results, model-comparison tables, and performance graphs that can be used for analysis and reporting.
